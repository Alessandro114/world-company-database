# Sample dataset (withdrawn)

The file `score_sample_100k.csv.gz`, published here from June 2026, has been withdrawn (October 2026). A licence review found rows from sources whose licence does not allow redistribution under CC BY 4.0 or has not been confirmed, and most revenue values in it were S.C.A.L.A. estimates rather than filed figures.

If you downloaded it, please do not redistribute it.

For company data with verified licences:

- the open registry datasets listed in [`README.md`](README.md#open-bulk-datasets-with-a-verified-licence), each with its licence;
- the [Score API](https://score.get-scala.com/api): every response carries `revenue_type` (`reported` / `estimated`) and a `data_licences` object with the attribution required for each country. Sources and licences: [score.get-scala.com/sources](https://score.get-scala.com/sources).
